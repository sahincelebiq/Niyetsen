Executive Summary

Niyetsen is a FastAPI + Expo monorepo: 53 JWT-protected API routes on Railway, Supabase Postgres, Gemini 3.1 for chat/plan/proof, RevenueCat IAP only. Auth gates are real (JWKS, prod locks, email-claim allowlist). The user-visible hole was not login crypto — it was the entry / billing UX: Settings opened an empty RevenueCat Customer Center (“Abonelik bulunamadı”) instead of the İlkbahar paywall.tsx.

This session patched that path and rebuilt the login screen to match İlkbahar. Remaining launch risk is Gemini preview quota (~250/day) and an offline subscription default that grants local premium. Combined risk score: 53 — High Risk (0 critical, 3 high, 5 medium, 2 low).

What Works Well

What Works Well

Prod cannot boot with auth or DB disabled

main.py:23-46 hard-fails if ENV=prod and AUTH_DISABLED, in-memory DB, empty CRON_SECRET, or empty RevenueCat webhook secret. This is a real launch lock, not a comment.

JWT allowlist ignores user_metadata.email

routes.py:187-190 + dev_accounts.py only trust the signed email claim. Testers cannot self-promote via metadata.

40 pytest files, scoring engine is pure

Game rules live in scoring_service.py without HTTP/AI. Tests force USE_SUPABASE_DB=false. Chat is free; premium is server 402.

IAP-only paywall does not invent prices

paywall.tsx waits for store strings; App Store 3.1.2 / Play honesty is coded, not documented only.

Implicit Contracts — Hidden Assumptions

plans.id is TEXT, not uuid

MASTER_PLAN + chat_threads migration 42804. supabase_repository FK writers.

"A developer adds plan_id uuid references plans(id) → migration fails 42804 because this unwritten TEXT rule"

Gemini 3 thinking_budget=0 is invalid

gemini_client._build_config uses thinking_level=low; fallback rebuilds config.

"A developer copies Gemini 2.5 thinking_budget=0 onto 3.1-pro → every chat 400 because the client contract is unwritten in the model docs the team remembers"

chat_threads degrade must never fail the chat

thread ops are try/except. Demo outage if removed.

"A developer lets thread insert raise → /chat 500 while Gemini succeeded because history is not on the critical path"

Behavioral Coupling — Invisibly Connected Modules

subscription_service ↔ mobile SubscriptionProvider

status==active (not DB free) opens second plan. Dev/tester emails stay free in DB. Change either side and the 2nd-plan gate or paywall CTA desyncs.

RevenueCat webhook ↔ scoring / premium writes

Webhook secret is prod-boot-required. Missed webhook + RC SDK delay = server 402 while store receipt is valid.

CLOSED_TEST_EMAILS env ↔ JWT email claim

Empty env = no short-circuit. Metadata email ignored. Change allowlist source without touching JWT parser and testers lose access.
